# Caleyez — What's in this repo

## Models
| Model | Run Folder | Weights |
|-------|-----------|---------|
| Global YOLO11l-cls | `runs/general_model_yolo11l5` | `weights/best.pt` |
| Israeli YOLO11l-cls | `runs/israeli_food_yolo11l` | `weights/best.pt` |
| XGBoost Arbiter | not trained yet | — |

## Scripts
| File | What it does |
|------|-------------|
| `train_general_model.py` | Trains the global food classifier |
| `train_israeli_food.py` | Trains the Israeli food classifier |
| `generate_arbiter_dataset.py` | Runs inference on val/test → CSV for XGBoost |
| `generate_yaml.py` | Generates data.yaml |

## What's NOT in the repo (too large)
- `datasets/` — image datasets
- `*.pt` epoch checkpoints — only `best.pt` of each final run is kept
- `arbiter_training_dataset.csv` — re-generated by `generate_arbiter_dataset.py`
