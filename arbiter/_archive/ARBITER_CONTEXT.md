# Nutritional Arbiter — Build Context

How the XGBoost arbiter was designed, what the data showed, and what every
decision means. Read this before touching `arbiter_train_xgb.py`.

---

## What the Arbiter Does

The system has **two YOLO11l-cls models**:

| Model | Classes | Role |
|---|---|---|
| **Global** | 142 | General food recognition |
| **Israeli** | 13 | Israeli/Middle-Eastern cuisine specialist |

For every image, both models run inference. The Arbiter is an **XGBoost classifier**
that reads the four confidence values + four class-name strings and decides
which model's prediction to trust:

| Label | Decision | Count | % |
|---|---|---|---|
| `0` | Trust Global top-1 | 34,185 | 81.9% |
| `1` | Trust Israeli top-1 | 2,085 | 5.0% |
| `3` | Trust neither (uncertain) | 5,492 | 13.1% |

There is **no label 2** in the dataset — routing to Global top-2 was never
the right answer. The arbiter is a 3-class problem: {0, 1, 3}.

## The Core Problem: "Overconfident Stupidity"

The Global model is **miscalibrated in the late training epochs**:
- Train loss epoch 97: 0.139 — Val loss epoch 97: 0.843 → **gap of 0.70**
- Val loss started diverging from epoch ~50 (0.719 → 0.843 by epoch 97)
- Peak val accuracy was at **epoch 68** (83.9%), not the final epoch

This overfitting caused the Global model to produce very high confidence
predictions that are wrong — e.g., classifying Jachnun as Croissant at 0.91
confidence. The mean Global confidence for label-1 cases (should use Israeli)
is still **0.753** — too high to filter by a naive threshold.

The Israeli model had **no such issue** — val loss 0.31–0.47, stable.
91.7% top-1 on 13 classes. Well-generalised.

**Key confidence stats by label:**
| Label | Global conf mean | Israeli conf mean |
|---|---|---|
| 0 (global correct) | 0.953 | 0.741 |
| 1 (Israeli correct) | 0.753 | 0.960 |
| 3 (both wrong) | 0.683 | 0.771 |

The routing signal is not "global confidence < threshold". It is the
**cross-model rivalry** — local vs. global confidence — combined with
whether the local model is predicting a known Israeli class.

## The 13 Israeli Classes

```python
ISRAELI_CLASSES = {
    "baklava", "bourekas_cheese", "falafel", "hummus",
    "jachnun", "malawach", "meorav_yerushalmi", "sabich",
    "samosa", "schnitzel", "shakshuka", "shawarma", "sufganiyah",
}
```

Five of these are **Critical** — their macro-nutrient profiles differ so
dramatically from likely Global confusions that a wrong routing causes the
largest nutritional errors:

```python
CRITICAL_ISRAELI = {"jachnun", "malawach", "sabich", "meorav_yerushalmi", "shawarma"}
```

Examples of the error magnitude:
- **jachnun** (~52% fat) confused with croissant/danish → ±45% calorie error
- **malawach** (pan-fried layered dough) confused with pancakes → ~30% fat underestimate
- **meorav_yerushalmi** (mixed organ meats) confused with grilled chicken → protein profile completely wrong

## Feature Engineering (22 features)

All features are derivable at **serving time** — no ground truth used.

| Feature | Type | Purpose |
|---|---|---|
| `global_top1_conf` | raw | Global model's certainty |
| `global_top2_conf` | raw | Global model's second guess certainty |
| `local_top1_conf` | raw | Israeli model's certainty |
| `local_top2_conf` | raw | Israeli model's second guess certainty |
| `global_conf_margin` | derived | `top1 - top2` for global (decision clarity) |
| `local_conf_margin` | derived | `top1 - top2` for Israeli |
| `global_entropy` | derived | 2-term Shannon entropy ≈ `-(p1·log p1 + p2·log p2)` |
| `local_entropy` | derived | Same for Israeli model |
| `local_over_global_ratio` | rivalry | `local_conf / global_conf` — >1 means Israeli more certain |
| `local_beats_global` | rivalry | binary: Israeli conf > Global conf |
| `conf_diff_local_minus_global` | rivalry | signed difference |
| `global_overconf_penalty` | penalty | `conf² × margin` when conf > 0.85, else 0 |
| `global_is_overconfident` | binary | global conf > 0.85 |
| `local_top1_is_israeli` | class flag | local top1 ∈ ISRAELI_CLASSES (always 1 by construction) |
| `local_top2_is_israeli` | class flag | local top2 ∈ ISRAELI_CLASSES |
| `global_top1_is_israeli` | class flag | global spontaneously mapped to Israeli class |
| `israeli_signal` | interaction | `local_top1_is_israeli × local_top1_conf` |
| `global_overconf_x_israeli_conflict` | interaction | penalty × israeli flag (key overconfidence detector) |
| `models_agree_top1` | agreement | global top1 == local top1 class |
| `global_top2_matches_local_top1` | convergence | did global almost predict the Israeli class? |
| `local_top1_class_enc` | identity | LabelEncoder of local class (13 values) |
| `global_class_israeli_rate` | target enc | fraction of times each global class → label 1 (142→1 feature) |
| `global_distrust_score` | composite | `penalty×(1+israeli) - global_margin + ratio×israeli` |

### The Overconfidence Penalty (critical formula)

```python
def _overconfidence_penalty(global_conf, global_margin):
    # Quadratic: at conf=0.99 the penalty is ~3.5x that at conf=0.85
    if global_conf > 0.85:
        return global_conf ** 2 * global_margin
    return 0.0
```

This is **zero for moderate confidence** and grows quadratically above 0.85,
targeting only the specific "very confident AND decisive" failure mode.

## Imbalance Handling

| Label | Count | Weight | Critical boost |
|---|---|---|---|
| 0 | 34,185 | 1.0 | — |
| 1 | 2,085 | **18.0×** | +2.5× if critical class |
| 3 | 5,492 | 6.5× | +2.5× if critical class |

- SMOTE was **rejected** — synthetic interpolation of encoded class names
  creates semantically invalid feature vectors
- `scale_pos_weight` was **rejected** — binary classification only; per-sample
  weights give finer control
- Weight 18.0 slightly exceeds the inverse-frequency ratio of 16.4 to add
  strategic over-weighting — a label-1 miss is worse than a label-1 false positive

## XGBoost Config

```python
XGB_PARAMS = {
    "objective":        "multi:softmax",
    "num_class":        4,          # labels 0,1,2,3 (2 unused but kept for safety)
    "n_estimators":     600,
    "max_depth":        7,
    "min_child_weight": 5,
    "learning_rate":    0.05,
    "subsample":        0.8,
    "colsample_bytree": 0.8,
    "gamma":            0.1,
    "reg_alpha":        0.5,
    "reg_lambda":       2.0,
    "seed":             42,
}
```

- `max_depth=7` — captures 3-way interactions (conf × israeli × margin)
- `reg_lambda=2.0` — strong L2 to prevent the label-0 dominant class from
  monopolising the tree structure
- `min_child_weight=5` — prevents leaf splits on fewer than 5 weighted
  samples (important for minority class leaves)

## Evaluation

- **Primary metric:** Macro-F1 (equal weight to all 3 classes regardless of size)
- **Secondary metric:** Label-1 F1 in isolation (Israeli routing recall)
- **CV:** StratifiedKFold-5 — preserves class distribution in each fold
- **OOF confusion matrix** — aggregated out-of-fold predictions give one
  unbiased confusion matrix across the full 41k dataset
- Final model is trained on **all data** after CV finishes

## How to Retrain

1. Update `DATA_PATH` in `arbiter_train_xgb.py` if the CSV moved
2. Run: `python arbiter_train_xgb.py`
3. Check CV output — target: Macro-F1 > 0.80, Israeli F1 > 0.75
4. If Israeli F1 is low, increase `WEIGHT_CLASS_1` (try 20–22)
5. If overall accuracy collapses, `WEIGHT_CLASS_1` is too high — reduce to 15

## How to Use in the App

```python
from arbiter_train_xgb import load_arbiter, predict_route

model, meta = load_arbiter("arbiter_xgb_model.json")

result = predict_route(
    model, meta,
    global_top1_class="bruschetta", global_top1_conf=0.91,
    global_top2_class="pizza",      global_top2_conf=0.04,
    local_top1_class="jachnun",     local_top1_conf=0.87,
    local_top2_class="malawach",    local_top2_conf=0.08,
)
# result["route"] → 1  (use Israeli model)
# result["route_label"] → "israeli_top1"
```

## Global Model — Should Have Been Early-Stopped

If the Global model is ever retrained:
- **Best val loss checkpoint:** around epoch 50–55
- **Best val accuracy checkpoint:** epoch 68 (83.9% top-1)
- Do **not** use final epoch 97 weights — overfitting is measurable
- Add `patience=15` on val loss to `EarlyStopping` callback

The current overfitting is the root cause of Overconfident Stupidity.
The Arbiter compensates for it but does not fix it.
