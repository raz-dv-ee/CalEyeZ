The 88.4% Ceiling

Why no arbiter — re-ranker, gate, or even a perfect oracle — can push the Caleyez system past ~88.4% overall accuracy, and what that means for the "90%+" goal.

Bottom line: 90%+ overall accuracy is mathematically impossible with the current two models. The limiting factor is the Global YOLO model itself (88.19% top-1 on 94.9% of the data), not the arbiter. To break 90%, the Global model must improve — no amount of arbiter engineering can manufacture accuracy the base model does not have.

1. The system, in one breath

Two CNN classifiers feed an XGBoost arbiter: a Global model (142 food classes) and an Israeli model (13 dishes). For each image the arbiter re-ranks the merged Top-5 candidates of both models and emits one final class. The question this document answers: how high can overall accuracy possibly go?

2. The four numbers that define the ceiling

Measured directly on the test split — these are not estimates:

The arithmetic

The best any arbiter can do is route every image to whichever model is right — a perfect gate. Even then: 

# Perfect routing = each image handled by its best model's top-1
overall_max = 0.949 × 88.19%   # global images → global model
            + 0.051 × 92.26%   # israeli images → israeli model
            = 88.40%
Because global images are 94.9% of the data, overall accuracy is chained to the Global model's 88.19%. The Israeli model is excellent (92.26%) but it only moves 5.1% of the result — lifting the ceiling barely 0.2 pp above the Global baseline.

3. Why an arbiter can't beat a model's own top-1

The arbiter only ever sees the two models' output probability vectors. A classifier's argmax is, by construction, the most probable class given that vector. An external re-ranker working from the same numbers therefore has no extra information to overturn the Global model on pure-global images — it can only add value where a second, independent opinion exists (the Israeli model, on Israeli food).

This is exactly what we observe — our best re-ranker scored below the Global baseline on the Global domain:

The Israeli model is overconfident on out-of-domain food. A naïve "use Israeli if its probability > 0.99" gate still misroutes ~10% of Global images — the Israeli 13-class softmax fires confidently on food it has never seen. This is why even the learned router (ROC-AUC 0.93 at detecting Israeli images) cannot reach the 88.40% perfect-routing line.

5. What this means for the project

The arbiter is done. v5 (84.99%) sits close to the achievable band. Further arbiter tuning yields diminishing returns — the remaining gap to 88.4% is the un-learnable "which model is right" routing noise, and the gap from 88.4% to 90% does not exist to be closed.

The only path to 90%+

Raise the Global YOLO's own top-1 accuracy. It governs 94.9% of the result, so every point it gains flows almost directly to the overall number:

If Global top-1 reaches……perfect-routing ceiling becomes

Concretely: more/cleaner training data, a larger backbone, longer training, or better augmentation for the Global model. That — not arbiter work — is the lever for 90%+.
